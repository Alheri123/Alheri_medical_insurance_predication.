# Alheri_medical_insurance_ cost _prediction.
Capstone Project applying Linear Regression to predict medical insurance cost using demographic and lifestyle data.


#Objectives

- Understand how demographic and lifestyle factors affect medical insurance costs.
- Apply Linear Regression to build a predictive model.
- Evaluate model performance using metrics such as R² and Mean Squared Error.

#Tools Used

- Python
- Pandas, NumPy
- Scikit-learn
- Jupyter Notebook / Google Colab

#Results

The model highlights smoking status, BMI, and age as strong predictors of insurance charges.  
Performance metrics show the regression model provides reasonable accuracy for cost estimation.

#Conclusion

This project demonstrates how Linear Regression can be applied to real-world datasets to predict costs, offering insights into key factors that drive medical insurance pricing.
